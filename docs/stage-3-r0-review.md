## 2. Отчёт о фактически выполненной статической проверке плана

Проверка выполнена над итоговым `docs/stage-3.md` (572 строки) скриптами `grep` и ручным сопоставлением.

**2.1 Существование Task ID.** Все 25 идентификаторов TK01–TK25 присутствуют ровно по одному разу как определения в таблице приёмки §2. В §2–§10 упоминаются только TK из диапазона TK01–TK25. Результат: **пройдено**.

**2.2 Существование Test ID.** Скриптом извлечены все токены `UT|FT|HT|PT|AT|ET|LOAD-<digits>` из текста (см. список ниже) и сопоставлены с диапазонами, заданными в таблице приёмки §2 (например HT-01…HT-08, FT-50…58, HT-220…232, LOAD-01…08). Каждое упоминание попадает в объявленный диапазон; несуществующих ID нет. Результат: **пройдено**.

**2.3 Отсутствие циклов.** Граф зависимостей направленный: у каждой задачи в колонке «Зависимости» только задачи с меньшим номером TK. Проверено для всех 25 задач по таблице §2. Циклов нет. Результат: **пройдено**.

**2.4 Доступность зависимостей к моменту Done.** Для каждой задачи приёмка разложена на Arrange/Act/Assert; Arrange использует только возможности зависимых задач. Ключевые случаи проверены: TK07 не требует TK09–TK19; TK11 требует TK09/TK10 (для E06 — начисление и списание); TK12 требует TK09/TK10/TK11; TK22 после TK17 (экспорт) и создающих задач; TK20 после TK06/TK16/TK05. Результат: **пройдено**.

**2.5 Согласованность фаз с графом.** Рёбра §3.1 (A→B→C→D→E) совпадают с зависимостями §2; блокирующие переходы перечислены в §3.1 и §9.1. Результат: **пройдено**.

**2.6 Покрытие B/T-подпунктов.** §8 содержит строки по каждому подпункту B01–B37 и по T01–T10 (включая составные a/b/c/…); общих строк «B01–B37 покрыты» нет. Для B20/B26/B33/B36 дополнительно проведена сквозная трассировка (задача → предшественники → подготовка → проверка → точный результат) в §10. Результат: **пройдено**.

**2.7 Соответствие протоколам и поправкам.** Протоколы stage-2 §4.2–§4.5, §5–§6 отражены в TK07/TK11/TK12/TK16/TK17/TK23; I201 — в TK05 и OpenAPI, I202 — в TK20 и OpenAPI. Результат: **пройдено**.

**2.8 Точность ожидаемых результатов.** Ожидания §4/§7 выводятся из B-правил (E01–E12, S1–S10, B1–B10); production-калькулятор источником не используется; неизменность выписки проверяется по составу/содержимому (FT-155/156/159). Результат: **пройдено**.
